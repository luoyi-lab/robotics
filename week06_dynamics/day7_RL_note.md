# 任务四 RL 三个概念

首先什么是RL reinforcement learning 强化学习
在传统控制（比如你前几周学的 PID）里，人类是“规则的制定者”。你根据经验，手动定好 Kp=80、Ki=30。系统就像个提线木偶，按照你写好的死规则运行。

RL 则是让机器自己“学会”规则。
它的核心机制是“试错（Trial and Error）”。
就像训练小狗：它做对了，你给块肉（奖励为正）；它做错了，你呵斥它（奖励为负）。经过成百上千次的训练，小狗就学会了怎么讨好你。

在机器人领域，RL 的形态是：你只设定一个“目标”（比如走到终点给奖励），然后让机器人在物理仿真环境里自己反复试，最后得到一套能用的控制策略。

为了把这种“试错”过程用数学严谨地表达出来，科学家发明了下面这三个概念：

# 1. MDP（马尔可夫决策过程）：RL 的数学模型
MDP 就是描述“机器人如何在环境里做决策”的数学框架。它由 5 个核心要素组成（结合你的机械臂来理解）：

S（State，状态）：机器人的“体检报告”。在机械臂里，**通常**是当前的关节角 + 角速度。

⚠️ **注意“通常”两个字。`(q, q̇)` 能当状态，前提是【理想刚体、无接触、无未建模动态】。**
真机有摩擦、有接触、有执行器延迟，`(q, q̇)` 往往**不够** —— 这就是为什么真机 RL 常用
“历史帧堆叠”，或者把一段历史观测拼进状态。这个前提不成立时，马尔可夫性也就断了。

（马尔可夫性的定义：未来只跟现在有关，跟过去无关。
它是 MDP 的**假设**，不是自动成立的**事实**。）

A（Action，动作）：机器人能采取的“操作”。在机械臂里，就是关节力矩（也就是你 PID 算出来的那个 u）

P（Transition Probability，转移概率）：环境的“物理规律”。在状态 S 下，你施加了动作 A，下一秒会变成什么状态？这由物理引擎（牛顿定律）决定，通常带有一定的随机性

R（Reward，奖励）：环境给的“分数”。机械臂离目标越近，给 +1 分；撞到桌子，给 -100 分。RL 的唯一目标就是让总分最高

γ（Discount Factor，折扣因子）：“近视眼程度”。取值 0 到 1 之间。它决定了机器人在乎眼前的利益（γ=0），还是在乎长远的未来（γ=1）。因为未来的奖励充满不确定性，所以通常要打个折

# 2. 价值函数（Value Function）：怎么评估好坏？
在训练过程中，机器人不能只看眼前的奖励。比如，你现在为了让机械臂往右走，可能会让它撞到墙（眼前被扣分），但长远来看，撞墙反弹后能更快到达目标（长远得分更高）

价值函数（Value Function），就是用来评估“当前状态潜力有多大”的数学公式。

V(s)（状态价值）：我现在待在这个位置，什么都不管，按照我现在的习惯（策略）一直玩下去，直到游戏结束，我平均能拿多少分？ 它评估的是状态本身的潜力。

Q(s, a)（动作价值）：我现在待在这个位置，如果强制先做一个动作 a，然后再按照习惯玩下去，能拿多少分？

一句话区别：
V(s) 是评估“环境”，
Q(s,a) 是评估“你在环境里做的具体动作”。比如你站在悬崖边（状态差，V 值很低），但如果你选择往后退一步（动作好，Q 值高），你就能活下来

# 3. 策略梯度（Policy Gradient）：怎么把策略调好？
这是一个机器学习算法名词，也是 PPO 算法的核心基础

什么是策略（Policy）？
策略就是机器人的“大脑”，它是一个函数：你给我一个状态 S，我告诉你该输出什么动作 A。
用神经网络表示时，输出通常是一个【概率分布】π(a|s) —— 例如“在状态 s 下，选这个动作的概率是 0.7”。

你之前用的 PID，其实是一个【公式形状固定、只有 3 个可调参数】的策略：

    u = Kp·e + Ki·∫e + Kd·ė

它的“策略函数”是人手工设计好的，能变的只有 Kp / Ki / Kd 三个数。
而神经网络策略有几千到几百万个权重 θ，形状是训练出来的。

策略梯度是干什么的？

⚠️ **这里最容易搞错的一点：策略梯度调的从来不是 Kp / Ki / Kd。**

一开始，网络权重 θ 是随机初始化的，策略很差（动作像无头苍蝇）。策略梯度会采样一批轨迹，算出每个动作的优势 A：

    A > 0    这个动作比平均水平好   →  提高它的概率
    A < 0    这个动作比平均水平差   →  降低它的概率

然后它顺着这个方向去**更新网络权重 θ**，让好动作的概率变大、坏动作的概率变小。

和你的 PID 的终极区别：

    你调 PID：你盯着波形图，手动输入 Kp=80。            你调的是【3 个数】。
    策略梯度：算法自己跑几万次，算出每个权重往哪边挪。   它调的是【几百万个数】。

**PID 的策略公式永远长那个样子；神经网络策略的形状，是训练出来的。**
这就是为什么 RL 能学到 PID 表达不了的东西（比如根据地形动态切换步态）。

总结一下：
PPO，就是一套基于“策略梯度”的 RL 算法。
它会自己撞个几千次墙，最后学会控制这根机械臂。这就是 RL 在机器人控制里的位置。

⚠️ **但有一句话不能说：「不再需要你懂运动学、懂动力学、懂 PID」。**

model-free 只是说“不需要显式的数学模型”，**不等于“不用懂机器人”**。
真实 RL 落地的 90% 工作量在：

    · 仿真环境怎么搭      →  要懂 URDF、关节限位、碰撞
    · 奖励函数怎么设计    →  不懂动力学，连“惩罚角加速度”都写不出来
    · 域随机化怎么加      →  不懂执行器特性（延迟、摩擦、饱和），随机什么？

**面试里问 RL，第一条永远是「你懂不懂机器人」，不是「你会不会跑 PPO」。**

### Day 1 · 周日 11/01 · IK 的几何直觉

**学**
- **IK 是什么**：FK 是 `θ → (x,y)`（唯一解，简单）；IK 是 `(x,y) → θ`（**可能多解，也可能无解**）
- **为什么会有两个解**：够到同一个点，肘可以朝上，也可以朝下
- **工作空间**：`|L1 - L2| ≤ √(x²+y²) ≤ L1 + L2`
  - 太远够不着、太近也够不着（不是越近越好）
- **余弦定理**：`r² = L1² + L2² - 2·L1·L2·cos(π - θ2)` → `cos θ2 = (x²+y²-L1²-L2²)/(2·L1·L2)`

**必须写出来**
- `day1_ik_geometry.py`
  - `reachable(x, y, L1, L2) -> bool`
  - 随机撒 2000 个点，可达的绿色、不可达的红色，画出来

**验证**
- [x] 拿 `(2, 0)`（伸直极限）→ 可达；`(2.01, 0)` → 不可达
- [x] 拿 `(0, 0)`（L1 = L2 时）→ **可达**（θ2 = π、θ1 任意），但这是**奇异位形**
  > ⚠️ 2026-11-01 修正：这里原来写的是「不可达」，**是错的**。`r = 0` 满足 `0 ≤ r`。
- [x] 把 `L1=1.0, L2=0.5` 画一次，**看到中间的洞**（`L1=L2` 时是实心圆，看不到洞）

**力扣**：无（周日留给机器人学）

### Day 2 · 周一 11/02 · IK 解析解 + 无解判定

**学**
```
c2 = (x² + y² - L1² - L2²) / (2·L1·L2)
若 |c2| > 1          → 无解（够不着）
s2 = ±√(1 - c2²)     → 正负两个 → 肘下 / 肘上
θ2 = atan2(s2, c2)
θ1 = atan2(y, x) - atan2(L2·s2, L1 + L2·c2)
```
- 🔑 必须用 `atan2(y, x)`，**不能用 `atan(y/x)`** —— 后者分不清象限，且在 x=0 时炸

**必须写出来**
- `day2_ik_solve.py`
  - `ik_2link(x, y, L1, L2) -> list[tuple[theta1, theta2]]`（0 个或 2 个解）
  - **对每个解，调用 W3 的 `fk_2link` 验证能还原 `(x, y)`**

**验证（今天的核心）**
- [ ] 100 个随机可达点 × 每个 2 个解 = 200 次 FK 往返，**全部 `allclose` 到 1e-9**
- [ ] 无解的点返回空列表，不抛异常
- [ ] 不要只 `print` 看着对 —— **必须 `assert` / `allclose`**（这是 W3 栽过的坑）

**力扣**：217 存在重复元素

**C++ / 附带**：给 `day3_two_link_arm_2.urdf` 补 `<collision>` 元素（和 `<visual>` 同几何即可）

### Day 3 · 周二 11/03 · IK 边界 + 奇异位形

**学**
- **奇异位形**：`θ2 = 0`（完全伸直）或 `θ2 = π`（完全折回）
  - 这时两个解**合并成一个**
  - 雅可比退化，末端在某些方向**动不了**
- **解析解 vs 迭代法**：两连杆有解析解；六轴一般没有，要用数值迭代（W5 之后会碰）

**必须写出来**
- `day3_ik_edge.py` —— 覆盖这几类点：
  - 边界点 `(L1+L2, 0)`、`(L1-L2, 0)`
  - 奇异点 `θ2 = 0` / `θ2 = π` 对应的位置
  - 原点 `(0, 0)`

**验证**
- [ ] 边界点能解出，且 FK 还原（可能只有一个解 —— 确认正常）
- [ ] 原点无解，返回空列表
- [ ] `c2` 因为浮点误差略微超出 `[-1, 1]` 时（比如 -1.0000000002）**要夹紧到边界**，不能直接判无解

### Day 4 · 周三 11/04 · 完整 D-H 四个参数 🔑

**学**
```
T_i = Rz(θ_i) · Tz(d_i) · Tx(a_i) · Rx(α_i)
      └── 关节那一块（会动）──┘  └── 连杆那一块（固定）──┘
```
| 参数 | 含义 |
|---|---|
| `θ_i` | 绕 `z_{i-1}` 转 —— **关节变量**（转动关节） |
| `d_i` | 沿 `z_{i-1}` 的偏移 |
| `a_i` | 沿 `x_i` 的连杆长度 |
| `α_i` | 绕 `x_i` 的**扭转角** ← W3 里一直是 0 |

**必须写出来**
- `day4_dh_matrix.py`
  - `dh_transform(theta, d, a, alpha) -> (4,4)`
  - 四个小矩阵 `Rz / Tz / Tx / Rx` **各写一个函数**，不许直接抄现成的 4×4

**验证**
- [ ] 令 `d=0, alpha=0` → 输出必须**逐元素等于** W3 的 `link_transform(θ, a)`
- [ ] 单独拿一个 `T_i`，平移列手算核对（应为 `[a·cosθ, a·sinθ, d]`）
- [ ] 打印出来逐项看，别只看「跑通了」

**力扣**：125 验证回文串（对比 234 回文链表：字符串用双指针，链表要「找中点+反转」）

### Day 5 · 周四 11/05 · D-H 建系三规则 🔑

**学 —— 三规则（标准型）**
1. **`z_i` 沿关节 `i+1` 的轴线**（所以 `z_0` 是关节 1 的轴）
2. **`x_i` 沿 `z_{i-1}` 与 `z_i` 的公垂线**，方向从 `z_{i-1}` 指向 `z_i`
3. **`y_i = z_i × x_i`**（右手定则，定死的，没自由度）

**零位 / 平行 / 相交三种特殊情况的处理**

**必须写出来**
- `day5_dh_table.md` —— **手画**两连杆的坐标系 + 列出 D-H 表（四个参数各多少）
- 结论应该是：`θ1` 变量、`d1=0`、`a1=L1`、`α1=0`；`θ2` 变量、`d2=0`、`a2=L2`、`α2=0`

**验证**
- [ ] **不看任何资料**，能在纸上画出两连杆的 `z0 z1 z2 x0 x1 x2`
- [ ] 写出的 D-H 表和这个结论对得上

**C++**：虚函数 / 虚表 / 继承 / 多态（重点：虚表指针 `vptr`、为什么析构要 `virtual`）

### Day 6 · 周五 11/06 · 标准型 vs 改进型 + 带 α 的例子 🔑

**学**
```
标准型：   T_i = Rz(θ_i)·Tz(d_i)·Tx(a_i)·Rx(α_i)        参数用 α_i,   a_i
改进型：   T_i = Rx(α_{i-1})·Tx(a_{i-1})·Rz(θ_i)·Tz(d_i)  参数用 α_{i-1}, a_{i-1}
                 └──── 块顺序反了，下标也错了一格 ────┘
```
- ⚠️ **混用不报错**：两种都乘得出一组合法的 4×4 变换，程序照跑，只是**机器人不是你想的那个**
- 看书第一件事：**翻到第一页确认它用哪套**

**必须写出来**
- `day6_dh_general.py`
  - `fk_from_dh_table(table, convention='standard'|'modified')` —— 支持**任意 n 轴**
  - 同时实现两套，同一张表分别算，**把差异打印出来**

**验证（⚠️ 今天才是真正的检验）**
- [ ] **必要条件**：两连杆 `d=0, α=0` → 和 W3 的 `fk_2link` 一致
      （但这只证明「简化版是特例」，**通过是理所当然的**）
- [ ] **真正的检验**：造一个 **`α ≠ 0`** 的三连杆（比如 α = 90°, 0°, -90°），
      写对应 URDF，在 PyBullet 里加载，**你的 D-H FK 和仿真读数必须一致**
- [ ] 同一张表用 standard 和 modified 分别算，**结果不同** —— 说明你确实分清了

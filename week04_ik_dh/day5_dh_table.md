## 建系三规则
```
为什么要建系？要能做到：拿到一个机械臂的物理结构 自己把坐标系建出来 并把四个参数列成表
先定Z，再定X，最后右手定Y  图文推导详见机器人学P90

(1) Z轴 代表转轴
规则：Zi轴 = 关节 i+1的轴线
最后一个关节 n后面没有关节 n+1了，所以Zn没有旋转轴可以依附。这时候它通常由你自由决定

(2)X轴 代表公垂线
规则：Xi轴 = Zi−1与 Zi的公垂线，方向从 Zi−1指向 Zi

(3)Y轴 右手定则唯一确定

原点 oi = xi 与 zi 的交点
zi 对应的是下一个关节 —— 这就是标准型和改进型最根本的区别之一
```
# 三种特殊情况：
```
(1) 两轴相交
问题： 两个 Z 轴交汇于一点，它们之间的“最短距离”为0，公垂线找不到了。
怎么办： 既然距离为0，参数 ai=0 公垂线方向就取两轴所在平面的法线方向，即 Xi取±(Zi−1×Zi)。

(2) 两轴平行
问题： 两条平行的线之间可以画无数条等长的垂直线，公垂线不唯一。

怎么办： 为了规范，我们强行规定：公垂线必须穿过上一个坐标系的原点 Oi−1。
这样选的话，两轴之间沿 X 轴没有平移（或说相对设定），所以di=0

(3) 两轴重合
问题： 两个轴变成了同一条直线，彻底乱了，公垂线无从谈起。

怎么办： 数学公式失效，直接“摆烂”。随便取一条垂直于 Z 轴的线当 X 轴即可（怎么算方便怎么来），通常设定 
ai=0，di随便分配（通常把偏移量分给其中一个就行）
```
# 例子A 两连杆平面臂
```
物理结构：平面两连杆，两个旋转关节的轴线都垂直于纸面向外
核心考点：两轴平行

在纸上画系（自己手画）

填表（D-H参数）
i        θ        d         a         α
1       θ1        0         L1        0
2       θ2        0         L2        0
```
# 例子B 肩部水平旋转+肘部俯仰
```
物理结构：这是一个三维空间机械臂。

关节 1 像人的肩膀，可以水平转动（轴是竖直的）。
关节 2 像人的手肘，可以上下俯仰（轴是水平的）。

中间由长 L1的连杆连接，末端由长 L2的连杆连接。

核心考点：两轴垂直（空间异面/相交）

填表（D-H参数）
i        θ        d         a         α
1       θ1        0         L1       +90°
2       θ2        0         L2        0

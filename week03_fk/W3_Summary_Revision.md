## 第 2 题 · 齐次变换
```
W3 的 link_transform 里这两行：

T[:3, :3] = Rz(theta)

T[:3, 3]  = R @ np.array([L, 0.0, 0.0])
(a) 为什么第二行必须是 R @ [L,0,0]？直接把 [L,0,0] 填进去会错在哪？
(b) 举一个具体角度说明：直接填错多少。（比如 θ = 90° 时，正确的是 (0,1)，直接填会得到什么？）

(a):因为连杆L的长度是定义在连杆自身的坐标系下的，必须要把它放到父坐标系下才对，所以必须经过当前关节的旋转矩阵旋转一下
(b):直接填会得到(1,0)
```
## 第 3 题 · URDF
```
(a) 你 URDF 里的 <origin xyz="..." rpy="..."> 描述的是关节相对父连杆的变换。它和 D-H 参数（θ/d/a/α）是什么关系？能不能把一张 D-H 表直接抄进 URDF？ 为什么？
(b) 画一根沿水平方向（x 轴）的连杆时，<cylinder> 为什么要加 rpy="0 1.5708 0"？

(a):它们是完全不同的两套描述体系。D-H 参数用四个特定顺序的参数（θ,d,a,α）来描述相邻连杆的变换；而 URDF 的 <origin> 用的是 XYZ 平移和 RPY 欧拉角（本质是 6 个自由度）
不能直接抄 D-H 表。你需要根据 D-H 的几何关系，算出子坐标系相对父坐标系的平移量和旋转角，然后再填进 URDF 的 xyz 和 rpy 里
(b):因为 PyBullet / URDF 标准中，圆柱体（cylinder）默认是沿着Z 轴生长的。要让它变成沿X 轴水平躺下，需要绕 Y 轴旋转 90 度
```
## 第 4 题 · C++ 智能指针
```
(a) 一句话说清这三个各解决什么问题：unique_ptr / shared_ptr / weak_ptr。
(b) 为什么 weak_ptr 不能直接 wp->val，必须先 lock()？
(c) 用一句话说清 RAII 是什么。

(a):
unique_ptr:独占所有权 解决不需要共享 但怕忘记delete的情况
shared_ptr:共享所有权 通过引用计数 解决多个人同时用一个对象 最后一个人夫负责销毁的情况
weak_ptr:弱引用 只是看着 通过lock()可以创建一个临时的shared_ptr 解决 shared_ptr 互相引用导致的“内存永远无法释放（死锁）”的问题

(b):因为 weak_ptr 只是个“旁观者”，它不拥有对象的生命周期，随时可能被别的 shared_ptr 给 delete 掉。直接访问会导致野指针崩溃。lock() 会安全地检查对象是否还活着，如果活着就返回一个临时的 shared_ptr（保证你使用时不会被别人删掉），如果死了就返回 nullptr
(c):Resource Acquisition Is Initialization（资源获取即初始化）。把资源的生命周期绑定到栈对象的生命周期上。对象一出生就获取资源（如 new、打开文件），对象离开作用域（析构）时自动释放资源
```
## 第 5 题 · 低通滤波
```
参数：τ = 0.1s，dt = 0.01s，输入从 0 阶跃到 1.0。

(a) α 等于多少？
(b) 第 1 拍输出多少？第 10 拍（t = 0.09s）大概多少？
(c) 如果输入本来就是 100：
有 initialized_ 时第一拍输出多少？
没有 initialized_ 时第一拍输出多少？
后者在真实机器人上会造成什么后果？

(a):α = dt/τ+dt = 0.0909
(b):
无 initialized_:
第1拍：y=0.0909×1+0.909×0=0.0909
第10拍：套用公式迭代10次 大约是0.61

有 initialized_：
第1拍和第10拍都是1.0

(c):
有 initialized_：第一拍输出就是 100 
无 initialized_：第一拍输出是 0.0909×100=9.09

如果电机静止在 100 度，没有 initialized_ 的话，滤波器输出会从 9.09 爬升。底层的 PID 控制器会算出巨大的误差（100 - 9.09），瞬间输出狂暴电流，导致电机猛烈抽搐、甚至损坏
```

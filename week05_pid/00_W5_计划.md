## 📅 每日安排

### Day 1 · 周日 11/08 · PID 直觉：三个字母各管什么

**学**
- **P（比例）**：`u = Kp · e`，`e = 目标 - 当前`
  - 只靠 P 会**振荡不停**（无阻尼）
  - 调大 Kp：响应快，但更容易振荡甚至发散
- **D（微分）**：`u = Kd · de/dt`
  - **看变化率，相当于"提前刹车"**
  - 只加 D 能消掉振荡，但会放大噪声
- **I（积分）**：`u = Ki · ∫e dt`
  - **消除稳态误差**（比如有重力一直往下拽，P 永远差一点）
  - 副作用：**积分饱和（windup）**

**必须写出来**
- `day1_pid_idea.py` —— **纯 Python 仿真，不用 PyBullet**
  ```
  被控对象：一维质量块    ẍ = u        （m = 1）
  目标：x 从 0 走到 1
  分四种情况画在同一张图上：
    ① 只有 P
    ② P + D
    ③ P + I
    ④ P + I + D
  ```

**验证**
- [ ] 只有 P 时，曲线**不停振荡**（等幅）
- [ ] 加 D 后，振荡**衰减并稳定**
- [ ] 加一个恒定扰动（比如 `ẍ = u - 0.5`，模拟重力），只有 P 时有**稳态误差**，加 I 后消除
- [ ] 四条曲线画在一张图上，图例清楚

### Day 2 · 周一 11/09 · 数字 PID + 三个分量单独实验

**学**
- **离散化**：`dt` 怎么来，`∫` 变成累加、`d/dt` 变成差分
  ```
  e = target - x
  integral += e * dt
  derivative = (e - e_prev) / dt
  u = Kp*e + Ki*integral + Kd*derivative
  e_prev = e
  ```
- ⚠️ **`dt` 必须稳定** —— 变步长会让 D 项抖

**必须写出来**
- `day2_pid_discrete.py`
  - `class PID`，`update(target, current, dt) -> u`
  - 三个分量各自单独开关，各跑一次，四条曲线对比

**验证**

### Day 3 · 周二 11/10 · 积分饱和 + 抗饱和 + 微分先行

**学**
- **积分饱和（windup）是什么**：执行器有上限（电机扭矩有限），但积分项还在往里累加
  - 现象：目标变了以后，**要等很久才动**（因为积分要"退"回来）
- **三种抗饱和手段**：
  1. **钳位（clamp）**：`integral` 限制在 `[-limit, +limit]`
  2. **条件积分**：输出饱和时**停止积分**
  3. **反计算（back-calculation）**：把「饱和值 - 未饱和值」反馈回去
- **微分先行（derivative on measurement）**
  - 问题：目标突变时，`de/dt` 会**冲击**
  - 解法：`derivative = -d(current)/dt`，**对测量值求导而不是对误差**

**必须写出来**
- `day3_antiwindup.py`
  - 给 PID 加 `u_limit`，实现**钳位**和**条件积分**两种抗饱和
  - 做一次「目标突然从 1 跳到 5」的测试，对比**有/无抗饱和**

**验证**
- [ ] 无抗饱和时，目标跳变后**明显迟钝**（overshoot 大、恢复慢）
- [ ] 有抗饱和时，响应干脆
- [ ] 微分先行：目标阶跃时 `u` **不再有尖峰**

**力扣**：209 长度最小的子数组
